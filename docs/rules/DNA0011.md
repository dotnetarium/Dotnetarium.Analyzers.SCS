# DNA0011: Server-side request forgery

CWE-918. Untrusted data reaches an outbound request destination. Use a fixed host allowlist and validate redirects and resolved network addresses.

Built-in sinks include `HttpClient` request methods, `HttpRequestMessage` URI construction or assignment, and `GrpcChannel.ForAddress`. An untrusted relative path combined with a fixed `BaseAddress` may leave the host fixed; review that context before treating a finding as host-control SSRF. A gRPC channel connects when a call is made, so a channel created but never used is not itself proof of a request.

This rule reports a candidate that needs review in the application's trust context. Configure severity with `dotnet_diagnostic.DNA0011.severity` in `.editorconfig`.

A complete literal HTTP(S) origin followed by an untrusted path/query suffix is
excluded when the request authority is fixed. This does not validate redirects
or DNS results. See [validation precision](../taint-validation.md).
