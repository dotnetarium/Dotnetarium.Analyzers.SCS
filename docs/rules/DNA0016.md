# DNA0016: Low PBKDF2 work factor

CWE-916. Reports an explicitly configured PBKDF2 iteration count below 100,000 in `Rfc2898DeriveBytes` constructors, its `IterationCount` property, static `Pbkdf2` methods, ASP.NET Core `KeyDerivation.Pbkdf2`, and `PasswordHasherOptions.IterationCount`. This catches clearly weak settings without warning on the ASP.NET Core Identity default.

The 100,000 cutoff is a conservative weak-setting signal, not an assertion that 100,000 is sufficient. Set a work factor appropriate to the hash algorithm, threat model, and performance budget. [OWASP's Password Storage Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html) recommends 600,000 iterations for PBKDF2-HMAC-SHA256 and a different count for HMAC-SHA512. Variable iteration counts are not evaluated by this rule.
