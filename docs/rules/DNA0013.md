# DNA0013: Weak encryption algorithm

CWE-327. Reports direct creation of DES, TripleDES, or RC2 through their .NET cryptography APIs. Use AES or a supported authenticated cipher for new encryption. Decrypting old data may require a documented exception.

The rule does not report CBC: CBC with a separate authentication mechanism is still a valid construction. It also does not infer a cipher from a runtime algorithm name.
