# DNA0013: Legacy cipher use

CWE-327. Reports direct creation of DES, TripleDES, or RC2 through their .NET cryptography APIs, Bouncy Castle `DesEngine`, `DesEdeEngine`, and `RC2Engine`, and those algorithms selected by a literal `CipherUtilities.GetCipher` name. Use a supported authenticated cipher for new encryption. This is a use candidate: creating a cipher solely to decrypt old data may be necessary and can be documented or suppressed.

The rule does not report CBC: CBC with a separate authentication mechanism is still a valid construction. It also does not infer a cipher from a runtime algorithm name.
