# DNA0002: OS command injection

CWE-78. Untrusted data reaches a process name or command argument. Avoid shell interpretation, choose executables from a fixed list, and pass validated arguments separately.

An untrusted executable name can select an unintended program. An untrusted `Arguments` string can change its command line; the risk depends on the launched program. `ArgumentList` escapes individual arguments and is not treated as an injection sink, but passing an argument to a shell command such as `sh -c` still requires review.

In Godot C#, this also covers the executable `path` passed to `OS.Execute`, `OS.ExecuteWithPipe`, and `OS.CreateProcess`. Their separate `arguments` arrays are not treated as command strings. Parameters of `[Rpc(MultiplayerApi.RpcMode.AnyPeer)]` methods are considered untrusted; authority-only RPC parameters are not.

This rule reports a candidate that needs review in the application's trust context. Configure severity with `dotnet_diagnostic.DNA0002.severity` in `.editorconfig`.
