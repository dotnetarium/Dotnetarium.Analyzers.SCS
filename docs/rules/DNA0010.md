# DNA0010: Insecure cookie configuration

CWE-614. A sensitive cookie disables HttpOnly or Secure, or uses SameSite=None. Review all three settings together. Cross-site cookies may need SameSite=None, but must also set Secure and have a deliberate CSRF strategy.

This rule reports a candidate that needs review in the application's trust context. Configure severity with `dotnet_diagnostic.DNA0010.severity` in `.editorconfig`.
