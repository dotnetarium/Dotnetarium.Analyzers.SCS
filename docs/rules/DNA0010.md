# DNA0010: Insecure cookie configuration

CWE-614, CWE-1004, CWE-1275. An authentication or session cookie explicitly disables HttpOnly or Secure, or sets `SameSite=None` without `SecurePolicy=Always`. An inline custom cookie is reported only for `SameSite=None` without `Secure=true`. Cross-site cookies may need `SameSite=None`; use `Secure` with it and apply a deliberate CSRF strategy.

This rule reports a candidate that needs review in the application's trust context. Configure severity with `dotnet_diagnostic.DNA0010.severity` in `.editorconfig`.
