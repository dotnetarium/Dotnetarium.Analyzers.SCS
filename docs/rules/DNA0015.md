# DNA0015: Fixed encryption IV or nonce

CWE-329. Reports literal or zero-filled IVs passed to `CreateEncryptor`, and literal or zero-filled nonces passed to `AesGcm.Encrypt`, `AesCcm.Encrypt`, or `ChaCha20Poly1305.Encrypt`. It also recognizes a fixed IV assigned to a local cipher before `CreateEncryptor` in the same method. Library coverage includes NSec `AeadAlgorithm.Encrypt`, Sodium.Core `SecretBox.Create` / `CreateDetached` and `SecretAead*.Encrypt`, and Bouncy Castle `Init(true, …)` with fixed `AeadParameters` or `ParametersWithIV`.

Generate a fresh IV or nonce for each encryption and store it with the ciphertext. In particular, repeating an AEAD nonce with the same key can compromise confidentiality and integrity. The rule follows simple local initializers only while they remain untouched; it skips values passed to other code before encryption. It does not analyze decryption calls or prove reuse across separate calls, fields, or processes.
