# DNA0021: XML external entity resolution

CWE-611. Untrusted XML reaches a parser proven to allow unrestricted external
entity resolution. Built-in sinks are stream/text-reader `XmlReader.Create`,
`XmlDocument.LoadXml`/`Load`, and `XmlTextReader.Read`.

For `XmlReaderSettings` and `XmlTextReader`, both explicit `DtdProcessing.Parse`
and an explicit `new XmlUrlResolver()` are required. `XmlDocument` requires the
explicit unrestricted resolver. Modern defaults, DTD parsing alone, null
resolvers, `XmlPreloadedResolver` and `XmlSecureResolver` do not trigger this rule.
A URI passed to `XmlReader.Create` is not treated as XML content by this rule.

Prefer rejecting DTDs and leaving the resolver null:

```csharp
var settings = new XmlReaderSettings {
    DtdProcessing = DtdProcessing.Prohibit,
    XmlResolver = null
};
using var reader = XmlReader.Create(input, settings);
```

When local DTDs are necessary, use a restricted/preloaded resolver. Do not enable
unrestricted URL resolution for untrusted documents. Entity expansion denial of
service is a different risk and is not covered by this diagnostic.

The unsafe-parser model follows local aliases, inline initializers, assignments
and definite branch state. It does not infer the behavior of custom resolvers,
unknown factories or settings changed by opaque helpers. Ambiguous parser state
is excluded rather than guessing unrestricted network access. Taint still follows
the normal interprocedural engine into the parsing input.

Configure severity with `dotnet_diagnostic.DNA0021.severity` in `.editorconfig`.
See [.NET XML security guidance](https://learn.microsoft.com/dotnet/fundamentals/code-analysis/quality-rules/ca3075).
