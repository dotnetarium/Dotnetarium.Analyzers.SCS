# DNA0014: ECB mode use

CWE-327. Reports `CipherMode.ECB` assignments, `EncryptEcb` calls, and literal Bouncy Castle `CipherUtilities.GetCipher` names with an `ECB` mode. ECB encryption exposes repeated plaintext blocks. `EncryptEcb` is direct evidence of encryption; a mode assignment or cipher selection may also be used only for legacy decryption. Prefer an authenticated encryption API such as `AesGcm` for new data.
