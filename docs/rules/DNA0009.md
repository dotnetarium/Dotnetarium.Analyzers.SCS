# DNA0009: Hardcoded secret

CWE-798. A literal credential or key is passed to a security-sensitive API. Load secrets from a managed secret store or deployment configuration.

This rule reports a candidate that needs review in the application's trust context. Configure severity with `dotnet_diagnostic.DNA0009.severity` in `.editorconfig`.

Built-in key sinks include .NET symmetric and AEAD APIs, Bouncy Castle `KeyParameter`, NSec `Key.Import` / `TryImport`, and Sodium.Core `SecretBox` and `SecretAead*` encryption and decryption methods. Literal byte arrays and inline zero-filled key arrays are reported; a key produced by a generator is not.
