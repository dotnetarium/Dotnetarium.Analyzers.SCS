# DNA0005: Open redirect

CWE-601. Untrusted data reaches a redirect target in MVC, Razor Pages, an HTTP response, or a Minimal API `Results.Redirect`/`TypedResults.Redirect`. Prefer `LocalRedirect` when only local destinations are allowed. An `IsLocalUrl` call is safe only when its result guards the redirect; the analyzer does not currently prove that guard and may report a guarded redirect for review.

This rule reports a candidate that needs review in the application's trust context. Configure severity with `dotnet_diagnostic.DNA0005.severity` in `.editorconfig`.
