# DNA0017: Hardcoded post-quantum private key

CWE-321. Reports literal private-key material imported through .NET 10 `MLKem`, `MLDsa`, or `SlhDsa` private-key import methods. It also reports literal PEM text containing a `PRIVATE KEY` marker. Public-key imports and key generation are not reported.

Load private keys from a protected secret store. The rule does not judge whether an approved PQC parameter set is strong enough for a particular protocol, and does not flag ML-KEM-512 merely for its parameter size. Some [.NET 10 PQC APIs](https://learn.microsoft.com/en-us/dotnet/core/whats-new/dotnet-10/libraries) remain experimental or platform-dependent.

Imports assembled through helper methods, fields, or configuration can escape this literal-only check.
