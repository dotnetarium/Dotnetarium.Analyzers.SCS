# DNA0008: Unsafe deserialization

CWE-502. Json.NET `TypeNameHandling` is set to a non-`None` constant, allowing JSON to select .NET types during deserialization. Keep `TypeNameHandling.None` or constrain types with a reviewed serialization binder. This rule reports a configuration candidate; it does not infer whether the application later deserializes untrusted JSON.

This rule reports a candidate that needs review in the application's trust context. Configure severity with `dotnet_diagnostic.DNA0008.severity` in `.editorconfig`.
