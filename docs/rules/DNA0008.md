# DNA0008: Risky Json.NET polymorphism setting

CWE-502. Json.NET `TypeNameHandling` is set to a non-`None` constant, allowing JSON to select .NET types during deserialization. Keep `TypeNameHandling.None` or constrain types with a reviewed serialization binder. This rule reports a setting candidate; it does not infer whether the application later deserializes untrusted JSON. It does not treat ordinary `System.Text.Json` deserialization as unsafe.

This rule reports a candidate that needs review in the application's trust context. Configure severity with `dotnet_diagnostic.DNA0008.severity` in `.editorconfig`.
