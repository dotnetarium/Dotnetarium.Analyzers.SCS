# DNA0001: SQL injection

CWE-89. A request value reaches a SQL command or query text. Use parameters supplied by the database API; allowlist SQL identifiers that cannot be parameterized.

Built-in sinks include Dapper query methods and command definitions, plus Npgsql commands, batch commands, and data-source commands. Supplying untrusted values as database parameters does not trigger this rule.

This rule reports a candidate that needs review in the application's trust context. Configure severity with `dotnet_diagnostic.DNA0001.severity` in `.editorconfig`.
