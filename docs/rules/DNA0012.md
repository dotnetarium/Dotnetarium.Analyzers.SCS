# DNA0012: Dynamic code execution

CWE-94. Untrusted data reaches dynamic C# code execution or a Godot expression with access to instance methods. Avoid evaluating user-supplied code with application objects; use a constrained parser for the required data format.

For Godot C#, the rule also follows untrusted text passed to `Expression.Parse` into the same `Expression` instance. It reports only when `Execute` is called with a visibly non-null `baseInstance` and `constCallsOnly` is omitted or explicitly `false`. A calculator-style `Execute()` call is not reported. Variable base instances whose non-null value cannot be established at the call site are currently outside this check.

This rule reports a candidate that needs review in the application's trust context. Configure severity with `dotnet_diagnostic.DNA0012.severity` in `.editorconfig`.
