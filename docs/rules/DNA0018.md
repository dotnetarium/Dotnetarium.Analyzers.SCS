# DNA0018: Untrusted external URI launch

CWE-20. Untrusted data reaches Godot `OS.ShellOpen`, which asks the host operating system to open a URI or file. Validate the scheme and destination against an allowlist before opening it.

Parameters of Godot `[Rpc(MultiplayerApi.RpcMode.AnyPeer)]` methods are treated as untrusted. Authority-only RPC parameters are not. The rule reports a candidate for review; the impact depends on the platform and URI handler.

Configure severity with `dotnet_diagnostic.DNA0018.severity` in `.editorconfig`.
