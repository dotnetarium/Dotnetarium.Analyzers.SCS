# DNA0004: Untrusted file path

CWE-22. Untrusted data reaches a file path, including an archive extraction destination. This does not prove that the path escapes an allowed root; applications may intentionally let users select files. Resolve sensitive paths against a trusted root and verify that the canonical result remains under it. `Assembly.LoadFile` and `LoadFrom` additionally deserve review as code-loading paths.

This rule reports a candidate that needs review in the application's trust context. Configure severity with `dotnet_diagnostic.DNA0004.severity` in `.editorconfig`.
